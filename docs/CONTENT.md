# Правила контента

## Цель
Подготовка ученика с 1 по 11 класс: теория, тест и контрольная работа по каждому предмету в каждом классе.
- Предметы, которые были в СССР (`era: "ussr"`), излагаются по советским учебникам.
  Под каждой темой блок `compare`: «Сейчас в российской школе».
- Предметы, которых в СССР не было (`era: "rf"`), излагаются по программе РФ (ФОП).
  Блок `compare`: «А как было в СССР».

## Где лежит контент
`src/entities/subject/data`:
- `subjects.json` — каталог предметов, правится вручную;
- `grades/<subjectId>-<класс>.json` — контент одного класса;
- `grades-index.json` — генерируется `pnpm content:index`, руками не править.

Схема — `src/entities/subject/model/types.ts`, валидатор — `src/entities/subject/lib/validate.ts`
(его запускают `pnpm content:check` и `pnpm test`). Образец структуры — `grades/math-1.json`.

## Нумерация классов
Современная, 1–11. До реформы 1986 г. начальная школа была трёхлетней, поэтому советский N-й класс
при N ≥ 4 соответствует современному (N+1)-му. Если материал в СССР шёл в другом классе, указать `ussrGrade`.
Пример: «Физика 6» Пёрышкина → `physics-7`, `ussrGrade: 6`.

## Базовые советские учебники (факты перед записью сверять)
Букварь — Горецкий; чтение — книги для чтения «Родная речь» (авторы по классам сверять); русский язык — Ладыженская, Бархударов; математика 1–3 — Моро; математика 4–5 — Виленкин;
алгебра — Макарычев; алгебра и начала анализа — Колмогоров; геометрия — Погорелов;
физика — Пёрышкин, Кикоин, Мякишев; химия — Рудзитис, Фельдман; астрономия — Воронцов-Вельяминов; литература — по советским учебникам литературы (9 кл. до 1986 г.: Зерчанинов, Райхин, Стражев «Русская литература»; для других классов учебник сверять перед записью).

## Правила
1. Объяснение писать своими словами по программе и логике учебника. Тексты учебников не копировать.
2. Один файл = один класс:
   - 4–6 тем по 250–500 слов (считаются слова `html`, без `compare`);
   - тест из 10–12 вопросов: есть все три вида `single` / `multiple` / `input`, оба типа `theory` / `practice`,
     по каждой теме хотя бы один вопрос;
   - контрольная из 5–7 заданий с весами `points` (1–10) и разбором `solution`.
3. HTML только с классами `rule`, `example`, `formula`, `note`, `table-wrap`. Теги: p, h3, h4, b, strong, i, em, u,
   br, sup, sub, small, span, div, ul, ol, li, table, thead, tbody, tr, th, td. Атрибуты: class, colspan, rowspan.
   Без скриптов, стилей и обработчиков событий. Знаки `<` `>` в тексте — `&lt;` `&gt;`.
4. В `compare` — только проверяемые различия (программа, учебник, порядок тем, ОГЭ/ЕГЭ). Без оценок и без политики.
   Если в факте не уверен — не писать его.
5. Ответы для `input` и контрольной перечислять во всех допустимых формах: `"10"`, `"10 см"`, `"на 10"`.
6. Для нового класса добавить `gradeDescriptions["<класс>"]` в `subjects.json`.
7. В уже опубликованном классе не менять порядок тем, вопросов и заданий: история ошибок детей ссылается на их
   позиции. Новые вопросы добавлять в конец.

## Порядок работы на каждый класс
`pnpm content:status` → написать JSON → `pnpm content:index` → `pnpm content:check`
→ коммит `feat(content): <subject>-<grade>`.
Очередь (её же печатает `content:status`): сначала математика/алгебра/геометрия 1–11, русский язык и чтение,
затем физика, химия и литература, затем остальные предметы.

Класс готов, когда `pnpm content:check`, `pnpm lint`, `pnpm test` и `pnpm build` проходят и каждый вопрос
ссылается на тему, где есть ответ.
