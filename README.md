# Школа СССР — школьная программа 1–11 класс

Тренажёр для ученика с 1 по 11 класс: теория, тест и контрольная работа по каждому предмету в каждом классе.

- Предметы, которые были в СССР, изложены по советским учебникам. Под каждой темой есть блок «Сейчас в российской школе».
- Предметы, которых в СССР не было, изложены по программе РФ (ФОП). Под темой есть блок «А как было в СССР».
- Классы нумеруются по-современному, 1–11. Если в СССР материал шёл в другом классе, это указано на странице класса.

Объяснения написаны своими словами по программе и логике учебников, тексты учебников не копируются.

**Открыть:** https://leaderdsn.github.io/ussr-school-prep/

## Деплой

Каждый push в `main` собирает и публикует сайт на GitHub Pages ([deploy.yml](.github/workflows/deploy.yml)): lint, тесты,
`content:check`, сборка с базовым путём `/ussr-school-prep/`. Один раз нужно:

1. **Settings → Pages → Source:** GitHub Actions.
2. **Settings → Secrets and variables → Actions:** добавить `VITE_FIREBASE_API_KEY`, `VITE_FIREBASE_AUTH_DOMAIN`,
   `VITE_FIREBASE_DATABASE_URL`, `VITE_FIREBASE_PROJECT_ID`, `VITE_FIREBASE_APP_ID` — значения из `.env.local`.
   Без них сайт работает, но без входа через Google.

## Запуск

Нужны Node.js `^22.18.0` или `>=24.12.0` и pnpm 11 (`corepack enable`).

```bash
pnpm install
pnpm dev          # http://localhost:5173
```

| Скрипт | Что делает |
|---|---|
| `pnpm dev` / `pnpm build` / `pnpm preview` | Dev-сервер, сборка с проверкой типов, просмотр сборки |
| `pnpm lint` / `pnpm test` | ESLint (включая границы FSD) и тесты Vitest |
| `pnpm content:status` | Какие классы написаны и что следующее в очереди |
| `pnpm content:index` | Пересобрать `grades-index.json` из файлов классов |
| `pnpm content:check` | Проверить каталог, все файлы классов и актуальность индекса |

## Стек

Vue 3.5, Vite 8, TypeScript (strict), Pinia, PrimeVue 4, Sass, Vitest. Архитектура — Feature-Sliced Design, границы слоёв
проверяет ESLint. Основа — [vue-fsd-starter](https://github.com/leaderdsn/vue-fsd-starter), отображение уроков и тестов —
по образцу [vue-interview-prep](https://github.com/leaderdsn/vue-interview-prep).

```
src/
  app/                    провайдеры, роутер, глобальные стили
  pages/home              выбор класса и предметов, общий прогресс
  pages/grade             темы класса, тест и контрольная: /grade/math-1/3, /test, /control
  widgets/subject-grid    карточки предметов выбранного класса
  features/run-quiz       тест: один ответ, несколько ответов, ввод ответа
  features/run-control    контрольная: баллы, оценка, разбор решений
  pages/family            прогресс детей для родителей
  widgets/child-report    отчёт по ребёнку: классы, попытки, ошибки, время
  features/manage-progress  экспорт, импорт и сброс прогресса
  features/select-child   выбор профиля в шапке
```

## Контент

Всё лежит в `src/entities/subject/data`:

- `subjects.json` — каталог предметов: эпоха (`ussr` / `rf`), классы, учебники, описания готовых классов;
- `grades/<предмет>-<класс>.json` — один класс: учебник, 4–6 тем с блоком сравнения, тест на 10–12 вопросов,
  контрольная на 5–7 заданий;
- `grades-index.json` — генерируется `pnpm content:index`, руками не правится.

Схема — [types.ts](src/entities/subject/model/types.ts), правила проверки — [validate.ts](src/entities/subject/lib/validate.ts),
образец — [math-1.json](src/entities/subject/data/grades/math-1.json). Правила написания и порядок работы описаны в
[docs/CONTENT.md](docs/CONTENT.md).

Новый класс: `pnpm content:status` → написать JSON → `pnpm content:index` → `pnpm content:check` → коммит
`feat(content): <предмет>-<класс>`.

## Прогресс детей

У каждого ребёнка свой профиль; ребёнок выбирает его кнопкой с именем в шапке, и все результаты записываются ему.
Страница **«Прогресс детей»** (`/family`) показывает по каждому ребёнку:

- сводку по классам: прочитанные темы, лучший результат теста, лучшую оценку за контрольную, число попыток;
- историю попыток: дата, тест или контрольная, результат, затраченное время, число ошибок;
- ошибки последней попытки: какие темы повторить, текст вопроса, ответ ребёнка и правильный ответ;
- время занятий по дням за 14 дней. Считается активное время: вкладка открыта и за последние 2 минуты был клик,
  нажатие клавиши или прокрутка.

Тест засчитывается от 80%, контрольная — от оценки «3» (50% баллов; «4» — от 70%, «5» — от 90%).

### Хранение

Данные всегда есть в браузере (`localStorage`), поэтому приложение работает без сети. Если задан Firebase, в шапке
появляется кнопка входа через Google: родитель входит своим аккаунтом на каждом устройстве, где занимаются дети, и
прогресс всех профилей хранится в Firebase Realtime Database по пути `schoolPrep/users/<uid>/children/<childId>`.
При первом входе данные устройства объединяются с аккаунтом без потерь, дальше изменения приходят на все устройства
в реальном времени. Каждый ребёнок записывается отдельным узлом, поэтому устройства разных детей не перезаписывают
друг друга. Без Firebase прогресс переносится файлом (экспорт и импорт на странице «Прогресс детей»).

Используется тот же Firebase-проект, что у life-tracker-planner и vue-interview-prep (вход через Google там уже
включён). Настройка:

1. **Realtime Database → Rules** — вставьте содержимое [database.rules.json](database.rules.json) и опубликуйте.
   Правила в базе общие для всех трёх приложений, поэтому файл содержит правила каждого (`households`,
   `interviewPrep`, `schoolPrep`). При изменении обновите файл во всех трёх репозиториях — если опубликовать
   правила без чужих узлов, другие приложения потеряют доступ к данным.
2. **Authentication → Settings → Authorized domains** — должен быть домен, где размещено приложение
   (`localhost` и `leaderdsn.github.io` там уже есть).
3. Для локального запуска — `.env.local` с `VITE_FIREBASE_*` (те же значения, что в life-tracker-planner;
   образец — [.env.example](.env.example)). Ключи веб-конфига публичные по своей природе, доступ ограничивают правила базы.

SDK Firebase загружается отдельным чанком и только у тех, кто включил синхронизацию.
