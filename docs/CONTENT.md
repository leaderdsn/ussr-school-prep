# Правила контента

## Цель
Подготовка ученика с 1 по 11 класс: теория, тест и контрольная работа по каждому предмету в каждом классе.
- Предметы, которые были в СССР (`era: "ussr"`), излагаются по советским учебникам.
  Под каждой темой блок `compare`: «Сейчас в российской школе».
- Предметы, которых в СССР не было (`era: "rf"`), излагаются по программе РФ (ФОП).
  Блок `compare`: «А как было в СССР».

## Где лежит контент
`src/entities/subject/data`:
- `subjects.json` — каталог предметов, правится вручную;
- `grades/<subjectId>-<класс>.json` — контент одного класса;
- `grades-index.json` — генерируется `pnpm content:index`, руками не править.

Схема — `src/entities/subject/model/types.ts`, валидатор — `src/entities/subject/lib/validate.ts`
(его запускают `pnpm content:check` и `pnpm test`). Образец структуры — `grades/math-1.json`.

## Нумерация классов
Современная, 1–11. До реформы 1986 г. начальная школа была трёхлетней, поэтому советский N-й класс
при N ≥ 4 соответствует современному (N+1)-му. Если материал в СССР шёл в другом классе, указать `ussrGrade`.
Пример: «Физика 6» Пёрышкина → `physics-7`, `ussrGrade: 6`.

## Базовые советские учебники (факты перед записью сверять)
Букварь — Горецкий; чтение — книги для чтения «Родная речь» (авторы по классам сверять); русский язык — Ладыженская, Бархударов; математика 1–3 — Моро; математика 4–5 — Виленкин;
алгебра — Макарычев; алгебра и начала анализа — Колмогоров; геометрия — Погорелов;
физика — Пёрышкин, Кикоин, Мякишев; химия — Рудзитис, Фельдман; астрономия — Воронцов-Вельяминов; литература — по советским учебникам литературы (9 кл. до 1986 г.: Зерчанинов, Райхин, Стражев «Русская литература»; для других классов учебник сверять перед записью).

## Правила
Цель — сохранить учебники на случай, если бумажных больше не будет. Поэтому класс пишется как **учебник, а не
справочник**: по нему ребёнок должен научиться сам, без бумажного учебника рядом.

1. Объяснение писать своими словами по программе и логике учебника. Тексты учебников не копировать.
2. Один файл = один класс, и он покрывает всю программу года:
   - 4–12 тем (параграфов, как главы учебника), каждая 300–1500 слов (считаются слова `html`, без `compare`
     и упражнений);
   - у каждой темы 3–10 упражнений «Выполни в тетради» (`exercises`): от простого к сложному, у каждого
     ответ или краткое решение для самопроверки (`answer`);
   - тест из 10–12 вопросов: есть все три вида `single` / `multiple` / `input`, оба типа `theory` / `practice`,
     по каждой теме хотя бы один вопрос;
   - контрольная из 5–7 заданий с весами `points` (1–10) и разбором `solution`.
3. Тема строится как параграф учебника:
   - вступление: жизненная ситуация, задача или вопрос, с которых начинается тема;
   - объяснение по шагам, новые слова выделены `<b>`;
   - правила и определения — в блоке `rule`, формулы — `formula`;
   - **не меньше двух разобранных примеров** (`example`): условие, решение по шагам, ответ;
   - рисунки и чертежи там, где они есть в учебнике: геометрические фигуры, отрезки и числовой луч, схемы к задачам,
     таблицы, графики функций, схемы опытов, разбор слова по составу;
   - в конце — короткий итог или вопросы «Проверь себя» (`note`).
4. Рисунки — встроенный SVG внутри `<figure>` с подписью `<figcaption>Рис. 1. …</figcaption>`:
   - у `<svg>` обязательны `viewBox` и `aria-label` с описанием рисунка (для тех, кто не видит картинку);
   - линии и фигуры: `stroke="currentColor" fill="none"`; заливка — `fill="currentColor"` или класс `soft`;
   - настоящие цвета, которые не должны зависеть от темы (флаг России), — классы `flag-white`, `flag-blue`, `flag-red`;
   - цвет — только классами: `accent` (цвет предмета), `red` (красная ручка учителя), `muted`; стиль линий —
     `thin`, `dashed`. Явные цвета (`#ff0000`, `red`) запрещены: рисунок должен работать в тёмной теме;
   - подписи — `<text>`; стрелки — `<marker>` в `<defs>`, ссылка `marker-end="url(#id)"`; id маркеров делать
     уникальными внутри класса (`arrow-t2`);
   - размер `viewBox` около 300×150…400×300, шрифт подписей `font-size="14"`.
5. HTML: теги p, h3, h4, b, strong, i, em, u, br, sup, sub, small, span, div, ul, ol, li, table, thead, tbody, tr,
   th, td, figure, figcaption и теги SVG (svg, g, defs, marker, line, polyline, polygon, rect, circle, ellipse,
   path, text, tspan). Классы: `rule`, `example`, `formula`, `note`, `table-wrap`, `accent`, `red`, `muted`,
   `thin`, `dashed`, `soft`. Без скриптов, стилей, картинок-файлов и обработчиков событий. Знаки `<` `>` в
   тексте — `&lt;` `&gt;`. Полный список атрибутов — в `src/entities/subject/lib/validate.ts`.
6. В `compare` — только проверяемые различия (программа, учебник, порядок тем, ОГЭ/ЕГЭ). Без оценок и без политики.
   Если в факте не уверен — не писать его.
7. Ответы для `input` и контрольной перечислять во всех допустимых формах: `"10"`, `"10 см"`, `"на 10"`.
8. Для нового класса добавить `gradeDescriptions["<класс>"]` в `subjects.json`.
9. В уже опубликованном классе не менять порядок тем, вопросов и заданий: история ошибок детей ссылается на их
   позиции. Новые вопросы и темы добавлять в конец. Тесты и контрольные можно править в админке (`/admin`).

## Порядок работы на каждый класс
`pnpm content:status` → написать JSON → `pnpm content:index` → `pnpm content:check`
→ коммит `feat(content): <subject>-<grade>`.
Очередь (её же печатает `content:status`): сначала математика/алгебра/геометрия 1–11, русский язык и чтение,
затем физика, химия и литература, затем остальные предметы.

Класс готов, когда `pnpm content:check`, `pnpm lint`, `pnpm test` и `pnpm build` проходят и каждый вопрос
ссылается на тему, где есть ответ.
